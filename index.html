0. Setup — do this once ~2 hours

The toolkit is three Claude skills you install in your own Claude account. You need a paid Claude plan and no coding at all. Click to expand or collapse.

Get the toolkit

  • 📦 CTC-Newsletter-Toolkit.zip — everything below, one filestart here
  • ctc-source-map.skill — finds your city's event sources. Run once, refresh quarterly
  • ctc-harvest.skill — collects the week's events into a spreadsheet. Weekly
  • ctc-assemble.skill — builds the issue. Weekly
  • START-HERE.md — the full setup and weekly guide. If this page ever disagrees with it, trust the guide
  • city-config-template.md — fill in once, upload to your Claude project

Install (from START-HERE.md)

  1. In Claude, go to Settings → Capabilities → Skills and upload the three .skill files.
  2. Turn on code execution in the same settings area — the skills need it to build your spreadsheet and document.
  3. Install the Claude for Chrome extension and sign in with the same account. Some event sites (Eventbrite especially) hide their data from simple requests; Claude reads those pages in your browser.
  4. Fill in city-config-template.md — chapter name, timezone, geographic scope, sign-off, footer. Save it as city-config.md. Takes ten minutes.
  5. Create a Claude project (e.g. "Boston Newsletter") and upload your city-config.md to it. Everything weekly happens inside that project.

5. You write stays human

Automate the lists. Write the words yourself. A 3,000-word issue contains roughly 80 words of human prose — and those 80 words are why anyone subscribes. Don't let Claude write them; generated prose reads like generated prose, and readers can tell.
